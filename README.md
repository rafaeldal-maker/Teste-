# Teste-# 🏓 Jogo Pong - Atração Interativa para a Mostra Técnica

Este projeto consiste numa versão clássica do jogo **Pong**, desenvolvida em HTML5, CSS3 e JavaScript. O jogo foi criado como uma atração interativa complementar para o stand do **Sistema de Monitoria** durante a Mostra Técnica.

## 🎯 Proposta de Integração no Stand
O jogo estará acessível diretamente no telemóvel dos visitantes através de um **QR Code** impresso no stand. 

A dinâmica funcionará da seguinte forma:
- **Engajamento:** Enquanto os visitantes aguardam pelo atendimento ou pela explicação do protótipo do Sistema de Monitoria, podem jogar uma partida rápida de Pong no próprio telemóvel.
- **Interatividade:** Cria um ambiente leve e descontraído no stand, chamando a atenção do público que passa pelo corredor.

## 🚀 Como Jogar
1. Aceda ao link do projeto via GitHub Pages ou leia o QR Code no stand.
2. Utilize as setas do teclado (Cima / Baixo) para mover a raquete e rebater a bola.

## 🛠️ Tecnologias Utilizadas
- **HTML5** (Estrutura e elemento Canvas)
- **CSS3** (Estilização e layout responsivo)
- **JavaScript** (Lógica do jogo, colisões e pontuação)
